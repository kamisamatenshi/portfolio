# Portfolio

Personal portfolio website for Chung Man Tse.

This repository is the source of truth for the portfolio website, its content, deployment configuration, and infrastructure notes.

## Workflow

After this initial repository bootstrap, changes should follow:

1. GitHub Issue
2. Issue-linked branch
3. Pull Request
4. Review and merge into `main`
5. Production deployment from `main`

## Current phase

Infrastructure bootstrap: connect the VPS, repository, web server, deployment flow, HTTPS, and portfolio domain before rebuilding the visual experience.
